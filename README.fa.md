# آمار دروس دانشگاه شهید بهشتی (SBU Course Stats)

مجموعه‌ابزاری کوچک برای استخراج، ذخیره و مصورسازی داده‌های عمومیِ اخذ دروسِ دانشجویان دانشگاه شهید بهشتی.

این پروژه از سرویس عمومیِ فهرست دروسِ دانشگاه داده جمع‌آوری می‌کند، دروس اخذشده‌ی هر دانشجو را در قالب JSON گردآوری می‌کند و یک داشبورد تعاملی می‌سازد که نشان می‌دهد هر درس با چه فراوانی‌ای اخذ شده است — با قابلیت فیلتر بر اساس سال ورود و مقطع تحصیلی.

> **توجه:** این پروژه صرفاً برای اهداف آموزشی و تحلیلی است و فقط روی داده‌هایی کار می‌کند که دانشگاه شهید بهشتی از پیش به‌صورت عمومی در دسترس قرار داده است. لطفاً مسئولانه از آن استفاده کنید.

[English README](README.md)

## امکانات

- **خزنده‌ی وب** که با پیمایش شماره‌ی دانشجویی‌ها، مقاطع، سال‌های ورود و کد دانشکده‌ها، داده‌ی دروس را جمع‌آوری می‌کند.
- **ذخیره‌گاه داده‌ی JSON** به همراه توابعی برای افزودن/به‌روزرسانی دانشجو، محاسبه‌ی شماره‌ی نیم‌سال و اصلاح مقدار مقطع.
- **داشبوردهای تعاملی** برای بررسی فراوانی دروس:
  - یک داشبورد HTML مستقل و ایستا مبتنی بر Chart.js.
  - یک داشبورد زنده‌ی Bokeh با چک‌باکس‌های سال/مقطع و راهنمای شناور (tooltip).

## نحوه‌ی ساخت شماره‌ی دانشجویی

هر شماره‌ی دانشجویی به این صورت تشکیل می‌شود:

<div dir="ltr">

```
<سال ورود (۲ رقم)> + <مقطع (۱ رقم)> + <دانشکده (۲ رقم)> + <شماره‌ی دانشجو (۳ رقم)>
```

</div>

- **مقطع:** `۲` کارشناسی، `۴` کارشناسی ارشد، `۵` دکتری.
- **دانشکده:** برای مثال `۲۲` برای ریاضی.

خزنده این شماره را به سرویس ارسال می‌کند و HTML بازگشتی را برای استخراج فهرست دروس دانشجو تجزیه می‌کند.

## نحوه‌ی استفاده

### ۱. استخراج داده

مقادیر `faculty`، بازه‌ی مقطع و بازه‌ی سال ورود را در [Spider.py](Spider.py) تنظیم کنید و سپس اجرا کنید:

<div dir="ltr">

```bash
python Spider.py
```

</div>

دانشجویانِ استخراج‌شده در فایل JSON تعیین‌شده در [JSONModifier.py](JSONModifier.py) (مقدار `DATA_PATH`) نوشته می‌شوند.

### ۲. ساخت داشبورد ایستا

<div dir="ltr">

```bash
python site.py
```

</div>

این دستور فایل `index.html` را تولید می‌کند که می‌توانید آن را مستقیماً در هر مرورگری باز کنید — بدون نیاز به سرور.

### ۳. (اختیاری) اجرای داشبورد زنده‌ی Bokeh

<div dir="ltr">

```bash
bokeh serve --show Plot.py
```

</div>

## نکات پیکربندی

- مقدار `DATA_PATH` را در [JSONModifier.py](JSONModifier.py) و [Plot.py](Plot.py) / [site.py](site.py) به فایل JSON موردنظرتان اشاره دهید.
- حلقه‌های `year`، `deg` و `faculty` را در [Spider.py](Spider.py) متناسب با ورودیِ موردنظرتان تنظیم کنید.
